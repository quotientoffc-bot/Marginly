# Marginly
**The Agency Operating System**

Unify your quotes, track your time, and protect your scope from one premium command center.

## Features
- **Scope Monitor**: AI-powered scope creep detection.
- **Client & Quote Management**: Secure quote generation and tracking.
- **Team HQ**: Real-time Slack-like feed and job claiming.
- **Admin Console**: Secure super-admin telemetry and analytics.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Database**: Supabase (PostgreSQL + Row Level Security)
- **Styling**: Tailwind CSS, Framer Motion, GSAP
- **Hosting**: Vercel
